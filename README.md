# Suryavansh Thakur - Personal Portfolio Website

A modern, responsive, developer-centric personal portfolio website built for **Suryavansh Thakur**, a B.Tech Computer Science & Engineering (CSE Core) student.

---

## 🚀 Features

- **Developer Aesthetic**: Tech-inspired theme with clean typography, dark background grid, neon cyan accents, and responsive card layouts.
- **Dynamic Content Management & Edit Mode**: Integrated **Edit Portfolio** dashboard allowing live updates to Hero, About Me, Technical Skills, Projects, Education, Certifications, Achievements, Currently Exploring, Resume, and Contact Details without editing code.
- **Project Showcase & Modal View**: Category filtering (Web Development, Python, C/C++, Java, AI/ML, Data, Other) with full-screen detailed project modals.
- **Responsive & Accessible**: Works across Mobile, Tablet, Laptop, and Desktop screens.
- **Dark / Light Theme Toggle**: Saves user theme preference in `localStorage`.
- **JSON Export / Import**: Easily export or import portfolio data as JSON backups.

---

## 🛠️ Tech Stack & Dependencies

- **Frontend**: React 18, Vite
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **Icons**: Lucide React
- **State & Persistence**: React Context API & `localStorage`

---

## 💻 Installation & Setup Instructions

Follow these steps to run the project locally on your machine:

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/suryavansh-thakur-portfolio.git
cd suryavansh-thakur-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open `http://localhost:3000` in your web browser.

### 4. Build for production
```bash
npm run build
```
